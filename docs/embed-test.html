Undergraduate advising: course planning

This test page stands in for the Allen School WordPress page where the prerequisite map will be embedded. It has enough text above and below the map that the page itself scrolls, so you can check that scrolling over the map moves the page instead of zooming the map.

Peer Advisers hold drop-in hours during the quarter. Bring your questions about course planning, registration, and how prerequisites fit together. The map below is an advising aid; always confirm your plan in MyPlan.

Students often ask which courses open up after the introductory sequence, how the 300-level courses connect, and which 400-level courses need which foundations. The map answers these visually; the text version answers the same questions as lists.

Planning ahead matters most for courses with long chains of prerequisites. Start from the course you want and look left to see what comes before it, or start from a course you have taken and look right to see what it unlocks.

If anything on the map disagrees with the UW Course Catalog, the catalog is correct. Please tell the Peer Advisers so the map can be fixed.

More about planning

Most students plan one or two quarters ahead. Check when courses are offered in the UW Time Schedule; not every course is offered every quarter.

Some courses list a minimum grade in a prerequisite. The map shows these as “≥ 2.0” on the line between the courses, and the text version says “minimum grade 2.0”.

Co-requisites are courses you take at the same time. The map lists them on the course instead of drawing a line.

Courses that are retired are not shown, but they still count if you have already taken them. An adviser can help you work out what they satisfy.

Questions about the degree requirements themselves go to an Allen School adviser, and the MyPlan degree audit is the authority on what you have completed.
